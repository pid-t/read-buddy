## 3 T01 区域采集和跳过结果查询

**范围**：新增 `src/utils/host/smart-filter/` 及必要测试，生产翻译入口保持现状。

1. 复用现有 DOM 过滤，采集区域 ID、父子关系、标签、角色、附近标题、有限文本样本和原节点引用。按设计限制数量及大小，未完整采集的区域照常翻译。
2. 定义供后台发送的区域数据和 `{"skipIds": string[]}` 结果类型。校验结果 ID，合并重复 ID，错误结果按全部照常翻译处理。
3. 提供节点是否跳过、父容器是否含跳过节点的查询，覆盖已有开放 Shadow DOM。无 AI 结果时，所有新增跳过查询返回 false。

**测试**：用少量合成 DOM 验证采样排除和长度限制，以及模拟导航跳过、正文保留、父容器查询和错误 ID。相关断言放在同一场景中。

```bash
pnpm exec vitest run src/utils/host/smart-filter
```

**通过条件**：接口可供后续调用，新增跳过只由传入的 AI 结果产生。

## 4 T02 AI 配置、迁移和后台调用

**范围**：配置类型、默认值、迁移及样例、后台消息和分类处理，复用 `src/utils/providers/model.ts` 与 AI SDK。

1. 加入 `translate.page.smartFilter: { enableAI: false, providerId: null }`，按现有方式增加连续版本迁移，保留用户的翻译范围及其他设置。
2. 定义一次分类请求和取消消息，传递请求 ID、区域数据和截止时间，标签页身份从消息发送方读取。
3. 跟随网页翻译 LLM 或使用指定的已启用 LLM，按设计提示词返回 `skipIds`。关闭开关或没有有效 LLM 时直接返回照常翻译。
4. 请求只执行一次，SDK 重试为 0。支持 2 秒总期限和取消，错误结果、网络错误或超时都返回照常翻译，复用现有消息和错误处理方式。

**测试**：配置默认值与迁移保留；模拟调用成功、关闭时调用为 0、错误结果和超时回退。取消与超时共用已有测试工具，避免重复搭建。

**通过条件**：后台接口可被内容脚本调用，失败可结束等待，现有翻译请求队列保持原行为。

## 5 T03 页面翻译接入和仅译文恢复

**范围**：页面管理器、DOM 遍历与文本提取、翻译执行、显示模式及现有变化监听。

1. 关闭开关时直接走现有路径。开启时，每次页面翻译启动只采集屏幕和预加载范围内的一批区域，最多等待 2 秒，其余区域正常处理。
2. 使用 T01 和 T02 的接口应用结果，遍历、父节点提取和写入使用同一份跳过结果。失败或超时后继续翻译仍可见的内容，离屏内容沿用现有视口处理。
3. 在仅译文快照和加载节点插入前检查现有外层父节点。含跳过或等待节点时整单元双语，保留跳过节点及其事件；其他单元使用原有仅译文路径，记录实际模式并按现有逻辑恢复。
4. 复用 DOM 变化监听清除失效结果。页面重扫、停止、关闭开关或 Provider 变化时取消等待，丢弃迟到结果，按设计完成清理与重扫。
5. 滚动、新增和展开后的未分类内容照常翻译，沿用现有段落切分和 Shadow DOM 遍历。

**测试**：一个导航加正文的组合页面覆盖开关与提取；一个混合仅译文场景验证节点身份、事件和恢复；必要的超时及过期结果用例。复跑所改模块对应的现有测试。

**通过条件**：AI 结果真正影响翻译，关闭时保持现有行为，失败能继续翻译，恢复后页面可正常操作。
