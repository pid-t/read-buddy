# 网页翻译 AI 区域识别设计

日期：2026-10-21

## 1 功能

在翻译设置中增加默认关闭的“AI 智能判断”开关。开启后，AI 判断页面中哪些区域可以跳过，比如导航栏、侧边菜单和操作按钮区。关闭时，按用户现有的翻译范围和显示模式处理。

AI 判断不清楚、调用失败或超时时，相关内容照常翻译。标题、正文、评论、内容列表和解释性旁注应保留，混合区域只跳过其中独立的界面部分。

## 2 实现原则

按最短路径接入现有代码：复用页面扫描、模型配置、后台消息、翻译队列和恢复逻辑，只增加采集区域、调用 AI、执行跳过结果所需的代码。

标签、角色、class 和位置帮助 AI 理解页面，新增跳过决定全部来自 AI。现有隐藏节点、可编辑内容、站点适配和用户排除规则继续生效，划词和手动节点翻译保持原行为。

## 3 处理流程

1. 页面翻译启动时检查开关。关闭就直接走现有流程。
2. 开启时，采集当前屏幕和预加载范围内的区域，发起一次 AI 请求。该批区域暂缓翻译，其余内容继续处理。
3. AI 返回要跳过的区域 ID。校验通过后，在遍历和文本提取时跳过对应节点。
4. 从开始等待到返回结果最多 2 秒。失败或超时后，立即继续现有翻译流程。

每次启动页面翻译最多请求一次。滚动、新增或展开后尚未分类的内容照常翻译。

## 4 发给 AI 的内容

用现有 DOM 遍历和过滤方法划分区域，为每个区域分配临时 ID，保存 ID 到原节点的对应关系。整页根节点只提供上下文。

每次最多发送 32 个区域，每区约 160 字符，总输入最多 12,000 字符。区域信息只包含 ID、父区域 ID、标签、角色、附近标题和少量可见文本。

采样排除隐藏内容、表单值、可编辑文本和扩展生成的译文。未完整采集的区域照常翻译，节点引用保存在内容脚本中。

提示词要求 AI 识别可跳过的界面区域，保留阅读内容和判断不清楚的区域。页面文本按待分析数据处理。

## 5 AI 返回结果

复用现有 AI SDK 和模型配置，返回结构为：

```json
{"skipIds": ["r2", "r4"]}
```

空数组表示全部照常翻译。用现有 Zod 校验返回结构，再确认 ID 属于本次请求。格式错误或出现未知 ID 时，本批内容照常翻译；重复 ID 合并处理。

应用结果前确认节点仍在页面上、对应内容未变化。页面重扫或区域变化后，相关结果失效。停止翻译或关闭开关时取消等待，丢弃迟到结果。

## 6 接入翻译和恢复

页面管理器保存本次分类涉及的节点和跳过结果，遍历、文本提取和写入使用同一份结果。提取父节点文本时，也要排除被跳过的后代。

双语模式保留原节点，只翻译允许的文本。仅译文模式沿用现有快照与恢复逻辑，在保存快照和插入加载节点前，检查 `outerTransNodes[0].parentElement`：

- 包含 AI 跳过节点或仍在等待分类的节点时，整个翻译单元使用双语，保留这些节点及其事件。
- 其余单元继续使用仅译文，包装节点记录实际模式，恢复时走对应的现有逻辑。

包含检查覆盖已有开放 Shadow DOM，并向宿主节点关联。范围较大的父节点可以整单元回退双语，直接复用现有段落切分。

复用现有 DOM 变化监听来清除失效结果，忽略扩展自己的译文写入。请求和写入前检查扫描与节点状态，避免过期结果影响页面。

关闭开关或切换 Provider 时，结束分类、清除结果，完成现有恢复和待执行 DOM 清理，再重新扫描。关闭状态直接使用原有显示路径。

## 7 配置和界面

| 配置                                    | 默认值与用途                                   |
| --------------------------------------- | ---------------------------------------------- |
| `translate.page.range`                  | 保留 `all`、`main`，新安装默认 `all`           |
| `translate.page.smartFilter.enableAI`   | `false`，控制 AI 区域识别                      |
| `translate.page.smartFilter.providerId` | `null`，跟随网页翻译 LLM，也可选择已启用的 LLM |

没有可用 LLM 时照常翻译。配置升级只补充新字段，保留已有选择。区域识别和 AI 上下文感知分别设置。

设置页复用已有开关和 Provider 选择组件，说明会发送少量页面内容并产生模型调用费用。发生双语兼容显示时，复用现有提示位置说明“部分区域以双语显示”，补齐现有语言文案。

## 8 测试和验收

自动测试使用模拟 AI 响应，复用已有用例，只补充以下行为：

- 开关关闭：分类请求为 0，现有翻译范围、显示和恢复行为保持一致。
- 开关开启：AI 指定的导航被跳过，正文继续翻译，父节点提取也遵守结果。
- 出错和变化：错误结果、超时、取消和过期结果都能继续翻译。
- 仅译文：混合单元回退双语，跳过节点的身份和事件保留，普通单元正常恢复。
- 配置迁移：默认关闭，用户已有配置保留。

同一场景合并验证相关接口，测试数量以能证明这些行为为准。每项任务运行相关测试、改动文件的 ESLint、类型检查和差异检查，完整测试和浏览器构建放到最终交付时运行一次。

真实效果用少量有代表性的文章、论坛和应用页面检查，确认导航减少翻译、阅读内容保留，记录所用模型和发现的问题。发现问题后修复并复查对应页面，普通测试保持真实模型调用为 0。
